WHAT IS IN EACH TIER?

Tier 0 / command wrappers
The registry-facing layer calls Vulkan, handles results and preserves the wrapper's output contracts.
cvk: 713 functions / scvk: 248
  Object and memory lifecycle: Creation/destruction, allocation/freeing, binding and host memory operations.
    cvkCreateBuffer
    cvkAllocateMemory
    cvkBindBufferMemory
  Command recording: Draw, dispatch, copy, rendering, acceleration-structure, video and other vkCmd operations.
    cvkCmdDraw
    cvkCmdDispatch
    cvkCmdCopyBuffer
  Queries and flattened siblings: Retrieve properties and requirements; flatten input Info structs where a sibling is required.
    cvkGetPhysicalDeviceProperties
    cvkGetBufferMemoryRequirements
    cvkGetBufferMemoryRequirementsInfo2
  Fixed-capacity enumeration: Perform Vulkan's count/fill protocol using caller arrays bounded by CVK_MAX_* capacities.
    cvkEnumeratePhysicalDevices
    cvkEnumerateDeviceExtensionProperties
    cvkGetPhysicalDeviceSurfaceFormats
  Submission and synchronization: Submit queues, acquire/present images, wait/reset fences and signal/wait semaphores.
    cvkQueueSubmit
    cvkQueuePresent
    cvkWaitForFences
  Dispatch and platform commands: Resolve extension commands or wrap platform-specific Vulkan calls in their platform files.
    cvkGetDeviceProcAddr
    cvkCreateWin32Surface
    cvkCreateXlibSurface
